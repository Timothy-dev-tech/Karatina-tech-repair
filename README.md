# Karatina Tech & Repair

🔗 Live Site: *coming soon*

A fictional business landing page for a phone and gadget repair shop, built from scratch using semantic HTML and modern CSS.

The project focuses on creating a realistic small-business website while practicing responsive layouts, CSS Grid, accessibility fundamentals, and clean information hierarchy without relying on frameworks or JavaScript.

## Tech Stack
- HTML5
- CSS3

## Features
- Responsive layout for mobile, tablet, and desktop screens
- Semantic HTML structure
- CSS Grid-based services section
- Accessible navigation and focus states
- Clean, business-focused UI design

## Status
✅ v1.0 complete (HTML/CSS only)

## Future Improvements
- Mobile hamburger navigation
- Contact form functionality
- Service inquiry booking flow

## Learning Goals
- Apply CSS Grid in a real-world layout
- Practice responsive design principles
- Build experience designing for business clients
- Develop a portfolio of frontend projects with varied use cases
